# Política de privacidade · Publicador Quintal de Negócios

O Publicador Quintal de Negócios é uma ferramenta interna da Quintal de Negócios. Ele serve só para publicar
conteúdo da própria empresa na página do Facebook e no perfil do Instagram da Quintal de Negócios.

- Não coleta, não armazena e não compartilha dados de outras pessoas.
- Usa a API da Meta apenas para publicar posts, reels e stories da Quintal de Negócios.
- O token de acesso fica guardado como segredo criptografado no GitHub e não é exposto publicamente.

**Exclusão de dados:** a ferramenta não guarda dados de usuários. Para revogar o acesso, remova o app em
Configurações do Facebook > Integrações comerciais. Dúvidas: pelo site https://quintaldenegocios.com.br.
